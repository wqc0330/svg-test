# OVERVIEW · 深渊回响

> 项目唯一入口。先看「当前制作单」，再打开对应场景卡；不必通读全部文档。

## 项目是什么

地下深渊题材 ARPG：玩家是一名回响探索者，潜入裂隙击杀深渊造物、回收遗物回响，越打越深、越换越强。

| 项 | 内容 |
|---|---|
| 类型 / 平台 | ARPG / PC 先行 |
| 目标玩家 | 喜欢暗黑美术与 build 成长的单机玩家 |
| 单局时长 | 单次下洞 10–15 分钟 |
| 设计稿分辨率 | 1920×1080（与各稿 viewBox 一致） |
| 工作台命令 | `npm run dev` → http://localhost:5173 |
| 团队 | 设计 + AI 协作 |

## 核心循环

进裂隙 → 清怪拾取回响 → 回城镶嵌强化 → 解锁更深层 → 下一轮进洞

## 制作主线

**定玩法 → 画场景 → 拆素材 → 生产素材 → 拼回场景 → 人工审核 → 实现交互 → 实机验收**

- 场景卡是当前制作的入口；本项目里「场景图」= 该场景的**设计稿 SVG**（根节点写 `data-scene-id`）。
- 占位素材可以验证玩法，但不能通过美术审核，也不能发版。
- 机器检查（`npm run check`）只证明文件合格；人判断它放进游戏是否好用。

## 目录约定

```text
public/designs/echoes-of-the-abyss/
├── project.json          项目元信息
├── docs/                 本套文档（目录树里可见）
│   ├── review/           人工审核单，人填写结论
│   └── specs/            复杂功能规格（可选）
├── screens/ hud/         界面设计稿
├── keyart/ environments/ characters/  概念设计稿
└── assets/
    ├── ref/              风格参考，只读，不进游戏
    ├── raw/              原始素材，未通过审核
    ├── scene/            场景效果图、标注图、合成预览
    └── approved/         人工通过的素材，正式稿只认这里
```

## 硬规则

- 正式设计稿不得引用 `assets/approved/` 之外的素材（`ref/` 只允许被风格板、场景概念稿引用）。
- **AI 不得代替人填写审核通过，也不得自行把素材标为已通过。**
- 场景、素材、交互和参数使用同一组 ID，禁止各写各的。
- 缺素材先用文件名以 `placeholder-` 开头的占位图，不擅自发明正式素材。
- 改核心玩法、内容边界或风格参考，记一行到 `04-DECISIONS.md`。
