# OVERVIEW · 矿脉行者

> 项目唯一入口。先看「当前制作单」，再打开对应场景卡；不必通读全部文档。

## 项目是什么

玩家扮演深入明亮卡通矿场的行者，在自动战斗中获取装备、矿石与玉石，通过空间有限和安全箱保底之间的取舍，决定继续深入或带着收益撤离。

| 项 | 内容 |
|---|---|
| 类型 / 平台 | 2D 竖屏手游；轻度 Roguelite＋背包整理＋资源收集；Cocos Creator 3.8.7 |
| 目标玩家 | 喜欢短局 Roguelite、背包整理和轻度收集的手游玩家 |
| 单局时长 | 10–15 分钟；6 场普通战＋1 场精英战＋1 场 Boss 战 |
| 设计稿分辨率 | 1080×1920，9:16 竖屏，与各稿 viewBox 一致 |
| 工作台命令 | `npm run dev` → http://localhost:5173 |
| 团队 | 策划、程序、美术实际成员姓名待填写；不虚构人员信息 |

## 核心循环

消耗体力下矿 → 自动战斗 → 装备三选一与空间整理 → 继续深入或撤离 → 仓库开矿并收藏玉石 → 再次下矿

核心决策：

1. **空间决策**：装备、矿石与玉石争夺有限背包格，装备还可旋转、移动、替换或丢弃。
2. **风险决策**：继续深入争取更高收益，或撤离保住背包；安全箱中的 2 件资源在任何结局均带出。

## 制作主线

**定玩法 → 画场景 → 拆素材 → 生产素材 → 拼回场景 → 人工审核 → 实现交互 → 实机验收**

- 本轮「场景图」包括可编辑的场景设计稿 SVG 与对应的效果图 PNG。
- SVG 位于 `screens/`，根节点以 `data-scene-id` 与场景卡一一锚定。
- PNG 仅作为 `assets/scene/SC-xxx/scene.png` 审核对照图，不被正式 SVG 引用。
- 本轮只生成 6 张完整界面场景图，不另做 Key Art、角色、怪物或道具概念图。
- 场景效果图必须由 game-images-mcp 生成，不以其他生图工具替代。
- 机器检查通过不等于美术或实机验收通过；AI 不代签人工审核。

## 硬规则

- 矿石和玉石每件固定占 1×1 格，局内不能叠加；装备按形状占格并可旋转。
- 装备栏 4×4，仅装备且属性生效；背包 6×6，可放装备与资源但装备不生效；安全箱固定 2 格，仅矿石和玉石。
- 撤离、通关带出背包与安全箱资源；死亡、放弃丢失背包，安全箱仍必定带出；装备在任何结局清空。
- 战斗外可调整背包与安全箱，战斗中锁定；空间不足必须可通过移动、丢弃或放弃新物品继续。
- 矿石局内不能开启；最终 Boss 不提供装备三选一；打造只预留，不建场景、不显示入口。
- 正式稿只认 `assets/approved/`；本轮 SVG 使用原生矢量，不引用未审场景 PNG。
- 改核心玩法、内容边界或风格约束时，必须在 `04-DECISIONS.md` 追加记录。
