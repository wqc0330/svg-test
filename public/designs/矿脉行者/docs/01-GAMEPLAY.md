# GAMEPLAY · 矿脉行者

> 只定义玩家行为、系统响应与已确认数值；画面与布局见 `02-SCENES.md`。

## 一、体验与边界

- **核心体验**：在不断深入的短局冒险中，用有限空间和有限保底承受风险，带着尽可能多、尽可能好的玉石收益返回基地。
- **设计支柱**：1. 自动战斗降低操作负担；2. 空间整理形成高频决策；3. 继续或撤离形成清晰风险抉择。
- **明确不做**：
  - 不实现打造配方、成功率、成品用途或属性，不显示打造入口。
  - 不做手动战斗、角色／道具独立概念稿、额外玩法场景、联机与付费系统。

## 二、核心循环

玩家在基地确认体力并下矿 → 获得固定初始装备并查看敌人 → 自动战斗 → 普通／精英胜利后装备三选一并处理概率资源掉落 → 整理装备栏、背包和安全箱 → 继续深入或主动撤离 → 按结局结算 → 仓库开矿获得并收藏玉石 → 用收藏成果开启下一局。

## 三、核心机制

### M01：体力下矿与局生成

| 项 | 内容 |
|---|---|
| 玩家输入 | 在基地点击「开始下矿」 |
| 前置条件 | 当前体力不少于 2；未存在未结算的旧局 |
| 规则 / 状态变化 | 进入第一层时一次性扣除 2 点体力，生成 8 层新局并发放训练矿镐、轻型护甲、旧手套、旧矿灯；单场战斗不再扣体力 |
| 成功反馈 | 体力立即更新，进入矿区层间页并展示第一层敌人 |
| 失败 / 边界反馈 | 体力不足时按钮禁用并显示恢复倒计时；撤离、死亡、通关均不返还体力 |
| 关联参数 ID | P001、P002、P003、P011、P012 |
| 出现在哪些场景 | SC-001、SC-003 |

### M02：自动战斗与跨战生命

| 项 | 内容 |
|---|---|
| 玩家输入 | 查看战斗过程；可切换 1×／2×速度；无手动攻击或施法 |
| 前置条件 | 已生成当前层敌人与双方战斗状态 |
| 规则 / 状态变化 | 双方自动攻击，3 个技能自动释放；生命跨战斗保留，普通胜利回复最大生命 10%；每深入一层敌人生命与攻击提高 15% |
| 成功反馈 | 普通／精英胜利进入装备三选一与资源拾取；Boss 胜利只结算资源并进入通关结算 |
| 失败 / 边界反馈 | 生命降至 0 进入死亡结算；背包遗失、安全箱保留、装备清空；战斗中储物空间锁定 |
| 关联参数 ID | P006、P007、P008、P009、P010、P011 |
| 出现在哪些场景 | SC-003、SC-004、SC-005、SC-006 |

### M03：装备三选一与三种储物空间

| 项 | 内容 |
|---|---|
| 玩家输入 | 选择一件装备或跳过；旋转、移动、替换、丢弃装备；在背包与安全箱间移动矿石／玉石 |
| 前置条件 | 普通或精英战胜利；最终 Boss 不触发装备三选一；当前不处于战斗中 |
| 规则 / 状态变化 | 装备栏 6×4（24 格）仅放装备且生效；背包 6×6 可放装备与资源但装备不生效；安全箱固定 2 格仅放矿石／玉石；装备占格形状固定为 8 种：1×1、1×2、2×2、2×3、2×2L形、2×3L形、2×3、3×2，且可旋转；资源每件 1×1 且不可叠加 |
| 成功反馈 | 新装备或资源落格，占用形状与剩余空间即时更新；奖励可跳过 |
| 失败 / 边界反馈 | 空间不足时明确标红冲突格，允许移动、替换、丢弃已有物品或放弃新物品，流程不得卡死；装备禁止进入安全箱 |
| 关联参数 ID | P004、P005、P012、P015、P016 |
| 出现在哪些场景 | SC-003、SC-005 |

### M04：深入、撤离与三类结局

| 项 | 内容 |
|---|---|
| 玩家输入 | 在层间页选择继续深入或主动撤离；在可放弃流程中确认放弃 |
| 前置条件 | 当前战斗已经结束且奖励处理完成；Boss 层胜利后自动按通关处理 |
| 规则 / 状态变化 | 深入后敌人增强且奖励提高；撤离／通关带出背包与安全箱资源；死亡／放弃丢失背包但安全箱仍带出；所有结局清空装备 |
| 成功反馈 | 结算页逐项展示安全箱保留、背包带出或遗失、装备清空及入库结果 |
| 失败 / 边界反馈 | 危险选择必须二次确认；结局只执行一次，不能重复入库或返还体力 |
| 关联参数 ID | P008、P011 |
| 出现在哪些场景 | SC-003、SC-005、SC-006 |

### M05：仓库开矿与玉石收藏

| 项 | 内容 |
|---|---|
| 玩家输入 | 切换矿石／玉石页；选择单个或批量开矿；查看玉石种类、品质与数量 |
| 前置条件 | 矿石已从上一局成功带入仓库；局内矿石不能开启 |
| 规则 / 状态变化 | 单个开矿消耗 1 件选中矿石；批量开矿消耗本次选中的全部矿石；结果进入玉石库存并汇总展示 |
| 成功反馈 | 展示开矿结果与新增玉石，库存种类、品质、数量同步更新 |
| 失败 / 边界反馈 | 无矿石时开矿按钮禁用；仓库汇总不代表局内可叠加；打造不在 MVP 处理 |
| 关联参数 ID | P013、P014 |
| 出现在哪些场景 | SC-002、SC-006 |

## 四、关键状态

| 状态 | 进入条件 | 玩家能做什么 | 离开条件 |
|---|---|---|---|
| 基地可下矿 | 体力 ≥2 且无旧局 | 查看体力、仓库、开始下矿 | 扣体力进入第一层，或进入仓库 |
| 基地体力不足 | 体力 <2 | 查看恢复倒计时、进入仓库 | 实时恢复至 ≥2 |
| 层间整备 | 战斗未开始或上一场奖励已处理 | 查看敌人、整理非战斗储物、继续或撤离 | 进入战斗或结算 |
| 自动战斗 | 当前层开始战斗 | 查看日志、切换速度 | 胜利整备／通关，或死亡结算 |
| 战后整备 | 普通／精英胜利 | 三选一、跳过、拾取与整理空间 | 完成奖励处理后回层间页 |
| 结算 | 撤离、通关、死亡或放弃 | 查看收益与损失、返回基地 | 入库完成并回基地 |
| 仓库开矿 | 仓库有可用矿石 | 单个／批量开矿、查看结果与玉石库存 | 返回基地或继续开矿 |
