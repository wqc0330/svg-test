# ASSETS · 矿脉行者

> 本轮只生产六张完整界面场景效果图，不生产独立角色、怪物、装备、图标或道具概念图。场景 PNG 仅供审核对照，不属于可直接进游戏的正式素材。

## 一、生产与审核链路

```text
已确认场景卡 → 场景效果图生产卡 → game-images-mcp
→ assets/scene/SC-xxx/scene.png → 尺寸与内容检查
→ 对照可编辑 SVG 设计稿 → 人填写审核单
```

```text
assets/ref        统一风格参考：骑士角色设定原图 + 派生的 anchor.png
assets/raw        本轮无独立散件原始素材
assets/scene      六张完整场景效果图与审核对照图
assets/approved   只有人工明确通过的正式素材才可进入；AI 不自行写入
```

AI 可以生成、修图和整理，但不能代替人审核通过，也不能把 `scene/` 中的效果图自行标记为 `approved`。

## 二、统一风格参考

风格真源是 `assets/ref/knight-character-sheet.jpg`（骑士·角色设定图，用户提供）；场景锚点是 `assets/ref/anchor.png`（以设定图为底、用 game-images-mcp 派生的同风格矿洞场景图）。所有场景效果图与后续素材都必须与二者同风格。

参考图风格要点：

- 2D 手绘 Q 版厚描边：近乎黑蓝的粗轮廓线，色块分明，少量硬边高光；不做写实渲染与柔和渐变。
- 深靛蓝暗色基底衬托高饱和点缀：缨红、剑金、技能紫；画面暗但不脏，主体始终清晰。
- 角色约二头身 Q 版比例，剪影夸张（红缨、披风、大剑）；装备与道具同用厚描边手绘。
- 特效为高饱和金、紫双色，带明确轮廓，不用写实粒子。
- 竖屏手游完整界面，画面比例 9:16；SVG 设计稿严格为 1080×1920，场景 PNG 保留 game-images-mcp 原生高清尺寸。
- UI 沿用厚描边木板/金属面板，暗底上文字用亮色，保证对比与信息层级；避免过度装饰遮挡文字。
- 效果图中的界面文字应为清晰简体中文；若模型文字不合格，以 SVG 设计稿为文字与布局真源，人工审核时驳回效果图而非自行过审。

| 文件 | 管什么 | 用法 |
|---|---|---|
| `ref/knight-character-sheet.jpg` | 角色比例、配色、描边与质感 | 生成角色、装备、怪物时作参考 |
| `ref/anchor.png` | 场景材质、光照、色温 | 生成场景效果图时的风格锚点 |

参考图只定调，不进 `approved/`。本次由「明亮卡通矿场」切换为「深靛蓝厚描边 Q 版」，原因与影响已记入 `04-DECISIONS.md`。

| 用途 | 色值 | 硬规则 |
|---|---|---|
| 背景 / 深靛蓝 | `#23233F` | 场景与界面底色，暗而不脏，主体保持清晰 |
| 主色 / 钢铁蓝灰 | `#4A5A78` | 盔甲、次级面板与结构体 |
| 辅色 / 银白 | `#C9D3E3` | 金属高光、暗底上的正文文字 |
| 强调 / 缨红 | `#B03A4E` | 主角识别色、敌方与危险强调 |
| 点缀 / 剑金 | `#D9A94F` | 主按钮、选中框、关键奖励 |
| 点缀 / 技能紫 | `#8A5BC8` | 技能特效、稀有品质 |
| 描边 / 近黑蓝 | `#161626` | 全部轮廓线与标题描边，保证清晰可读 |

## 四、机器与内容检查

`npm run check` 校验 SVG 标注规范；场景 PNG 额外核对尺寸、完整性与路径。自动检查不等于人工审核通过。

| 检查项 | 通过标准 |
|---|---|
| 文件 / 命名 | 每个 SC 目录仅有对应 `scene.png`，文件名小写且路径与场景卡一致 |
| 尺寸 | SVG 严格为 1080×1920；PNG 保留原生竖屏尺寸（1440×2560、1152×2048、941×1672 或 720×1280），完整不透明且无意外裁切 |
| 内容完整性 | 是完整界面场景，包含场景卡指定区域；不是角色、怪物或道具散图 |
| 风格一致性 | 2D 手绘厚描边、深靛蓝暗色基底、缨红／剑金／技能紫点缀、木支架与轨道矿车元素统一，对照 `assets/ref/anchor.png` |
| 文字与 UI | 中文可读、按钮与网格可辨；文字或布局错误必须驳回效果图，SVG 始终是文字真源 |
| 引用 | 正式 SVG 不引用 `assets/scene/`；后续正式素材只能使用人工通过后的 `assets/approved/` |

## 五、人工审核：正式入口

1. 审核人同时查看对应 SVG、场景 PNG 和 `docs/review/SC-xxx.md`。
2. 对场景整体判断风格统一、主体清晰、层级正确、语义明确、交互可辨认。
3. 对 AI 效果图的文字乱码、网格数错误、缺区域、额外界面或风格偏移给出可执行修改意见。
4. 人工结论只能由审核人填写；AI 不代签，不因生成成功就写通过。
5. 本轮 PNG 保持在 `assets/scene/`；若后续拆出正式游戏素材，需另建生产卡、重新过审并进入 `approved/`。
