## 已否决的方案

| 方案 | 否决原因 | 日期 |
|---|---|---|
| 暗黑写实矿洞风格 | 与已确认的明亮卡通矿场方向冲突 | 2026-10-31 |
| MVP 显示打造入口或实现打造配方 | 打造只预留，不可用入口会制造误解 | 2026-10-31 |
| 手动攻击或手动施法 | 核心战斗定位为自动战斗 | 2026-10-31 |
| 矿石／玉石局内叠加 | 每件资源固定 1×1，堆叠会削弱空间决策 | 2026-10-31 |
| 装备放入安全箱或成功撤离后带出装备 | 安全箱仅资源；装备任何结局均清空 | 2026-10-31 |
| 死亡时清空安全箱 | 安全箱是最低收益保障，任何结局均带出 | 2026-10-31 |
| 最终 Boss 后继续装备三选一 | 关底只提供资源与通关结算 | 2026-10-31 |
| 使用其他生图工具替代 game-images-mcp | 用户明确指定唯一生图工具 | 2026-10-31 |
| 把场景 PNG 直接当作正式 SVG 设计稿 | 不可编辑、不可检索，也不符合语义标注规范 | 2026-10-31 |
