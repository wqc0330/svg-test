# SHIP（模板）

> 发版前逐条打勾，一条不过就不发。
> 10 条封顶。想加新的，先删一条。

- [ ] 从全新存档能一路通关，中途不崩溃
- [ ] 退出重进，进度不丢
- [ ] 断网、切后台、锁屏后返回，不崩溃不卡死
- [ ] 最低配设备稳定 30 帧（先写清最低配是哪台机器）
- [ ] 设计分辨率下 UI 不裁切、不重叠，所有按钮可点、无死链
- [ ] 每个正式场景均有审核记录；素材经人工通过并全部位于 `assets/approved/` 下
- [ ] `npm run check` 全部设计稿 0 错误，无占位符残留（TODO / lorem / 测试文本 / `placeholder-` 素材）
- [ ] 音量、语言、画质等设置改完能保存并生效
- [ ] 首次启动的权限申请、隐私政策、合规材料齐全
- [ ] 商店页素材与实机一致（截图是真实游戏画面）

---

**用法**：每次发版前跑一遍，正常应该在 2 小时内完成。
超过 2 小时，说明你在靠人肉补测试，该把其中几条写成自动化了。
